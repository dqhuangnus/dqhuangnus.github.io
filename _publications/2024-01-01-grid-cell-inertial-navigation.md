This work addresses the problem of accuracy degradation in inertial navigation systems caused by the accumulation of IMU errors over time. Drawing on the path integration mechanism of grid cells in rodents, a bio-inspired network is developed to reduce accumulated navigation error, with an LSTM-based network used for further error compensation. Using the PSINS toolbox to generate inertial navigation data, the approach reduced navigation error to 0.0062 m with the holistic method and 0.10 m with the segmented method, offering a new avenue for compensating inertial navigation drift.
